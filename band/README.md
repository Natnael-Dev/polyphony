# BAND Desktop Seat Adapters

This directory contains standalone Python adapters that connect BAND Desktop seats to the local OpenCode gateway (or direct Gemini SDK).

## Structure
- `run_architect.py`: Adapter script for `@architect` seat.
- `run_developer.py`: Adapter script for `@developer` seat.
- `run_qa_auditor.py`: Adapter script for `@qa-auditor` seat.
- `opencode-config.json`: Sample OpenCode gateway configuration.
- `requirements.txt`: Python package requirements.
